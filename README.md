## Playwright with JavaScript and Jest
This an end-to-end testing sample project using Playwright with JavaScript and Jest
- Scripted for login
- Implemented page object model
- Added jest html reports
- Included screenshots if test fails

## Pre-requisites

- [NodeJs](https://nodejs.org/en/)
- [Visual Studio Code](https://code.visualstudio.com/)
- [Introduction to JavaScript](https://testautomationu.applitools.com/javascript-tutorial/)
- [Jest](https://www.npmjs.com/package/jest)

## How Run

- Clone the repository or download 
- Install npm
- Run npm test
